# Frevo!（ko-ko-ya）アコースティックギター タブ譜

`outputs/target/best/acoustic_guitar.wav`（Champion パイプラインで抽出したギター stem）から自動採譜したギターのタブ譜です。
作曲は笹子重治、原曲の録音は 2011 年。

## ファイル

| ファイル | 内容 |
|---|---|
| [`frevo_guitar_tab.pdf`](frevo_guitar_tab.pdf) | 五線譜（ト音記号 8vb）＋ TAB 譜の浄書 PDF。コード名、全小節の小節番号、4 小節ごとの録音内時刻つき |
| [`frevo_guitar_tab.txt`](frevo_guitar_tab.txt) | テキスト（ASCII）タブ譜。1 文字列 = 16 分音符 1 つ |
| `frevo_guitar_tab.gp5` | Guitar Pro 5 形式（Guitar Pro / TuxGuitar / MuseScore / Songsterr 系で開けます）。コードダイアグラムつき |
| `frevo_guitar_tab.musicxml` | MusicXML 4.0（五線譜＋ TAB の 2 段、弦・フレット情報つき。MuseScore 等で編集可） |
| `frevo_guitar_tab.mid` | 録音と時間軸が一致した MIDI（120 BPM 固定、1 拍 = 0.5 s）。DAW で原曲に重ねて確認できます |
| `frevo_guitar_tab_notes.csv` | 全ノート一覧：小節・拍・16 分位置・発音/終了時刻・音名・弦・フレット・確信度 |
| `frevo_guitar_tab.ly` | PDF の LilyPond ソース |

| [`verification.md`](verification.md) / `verification.json` | 検証結果 |

## 読み方

- **チューニング**：レギュラー（E A D G B E）。録音は A4 ≒ 442 Hz（+9 cent）。
- **拍子・テンポ**：2/4、♩ ≒ 156。16 分音符はブラジル音楽特有の「訛り」（2 つ目の 16 分がやや遅く、4 つ目がやや早い）で演奏されていますが、譜面は通常の 16 分で書いています。
- **小節番号**：ギターが入る 0:03.3 を 1 小節目としています（それ以前のイントロはギター休み）。各小節に録音内の時刻を併記。
- **奏法**：親指のベース（多くの小節で拍頭に、ルートと 5 度を交互に）と、裏拍・16 分裏に入るコードの刻みが基本形です。
- **コード名**：採譜したノートから推定したもので、参考表示です（ベースが 8 分先行する進行にも対応）。
- **曲の流れ**：A テーマ（Gm7–C7(9)… F7–E7–E♭7–D7 の半音下降ドミナント）が小節 1・17・33・65・117・129 付近に現れ、81 小節目から音の少ない対照部、143 小節目付近から C♯7 を経て F♯ へ転調するコーダに入り、F♯6 のトレモロで終わります。

## 採譜方法

1. **チューニング推定**：スペクトルピークの周波数ヒストグラム（100 cent 周期の円周平均）で +9 cent を検出し、リサンプリングで補正。
2. **ノート検出**：高分解能オンセット／オフセット回帰 CRNN（Kong et al. 2021 のアーキテクチャ）に、Riley らのギター用チェックポイント（`xavriley/midi-transcription-models` の `guitar_kroma.safetensors`、MIT）を使用。safetensors のみを読み込み、pickle 形式の重みは使っていません。窓位相を 2 通りずらした推論を平均。
3. **ビート・小節**：親指ベースを重み付けしたギター自身のオンセット包絡でビート追跡 → 全オンセットによる最小二乗でビート時刻を補正 → 16 分の訛り位置をクラスタリングして量子化 → 和声変化とベース位置から小節頭を決定。
4. **弦・フレット割り当て**：（運指 × 左手ポジション）の状態空間で Viterbi。ポジション移動・ストレッチ・鳴っている音を切らないこと等をコスト化し、GuitarSet（奏者が実際に弾いた弦の正解つきデータ）で重みを調整。構造上弾けない和音や無理なストレッチになる場合は、確信度の低い音から落とす（ベース音は優先的に残す）。
5. **コード名**：8 分単位のテンプレート照合＋ Viterbi 平滑化。
6. **書き出し**：ASCII / MusicXML / Guitar Pro 5 / LilyPond→PDF / MIDI / CSV。

## 精度の目安

正解譜が存在しないため、公開データでの性能と、この曲での整合性チェックの両方で評価しています。

| 指標 | 値 |
|---|---|
| ノート検出（GuitarSet マイク録音 60 抜粋、学習に未使用、onset F1 / 50 ms） | **0.80**（適合率 0.87、再現率 0.75） |
| 弦の割り当て（GuitarSet 保留データ、奏者と同じ弦を選んだ割合） | **67.8 %**（最低フレット法は 43.8 %） |
| この曲：タブの各音に対するモデルの発音確信度（中央値） | 0.86（0.4 未満は 1255 音中 35 音） |
| この曲：タブに含まれない強い音響活性（80 ms 以上） | 20 箇所 |
| この曲：原音 stem とタブ再合成音のクロマ一致（小節中央値） | 0.87（0.7 未満の小節なし） |
| この曲：独立モデル Basic Pitch との一致（onset F1） | 0.64（Basic Pitch 側の倍音誤検出が多く、主に相手側の誤り） |
| 演奏可能性 | 最大ストレッチ 4 フレット、最高 10 フレット、5 フレット超の跳躍なし |
| 窓位相を変えた再推論での一致率 | 98.4 % |

## 限界・注意点

- 自動採譜です。和音の内声の取りこぼし（GuitarSet での再現率 0.75 相当）や、密な和音でのまれな余分な音があり得ます。
- 弦・フレットは「音高を満たす自然な運指」の推定で、奏者（笹子重治氏）の実際の運指と一致する保証はありません。同じ音で別ポジションの押さえ方も成立します。
- 分離 stem（Champion、検証 SDR 7.6 dB）由来のため、ヴァイオリン・クラリネットの漏れがわずかに残ります。stem と残差の比較では、タブに入った音のうち残差側にも同じ音があるのは約 2 % でした。
- エンディングのトレモロは 16 分の刻みとして簡略化しています。
- まず耳で確認したい小節（クロマ一致が低い順）：`verification.md` を参照。

## 再現

```bash
uv sync --extra cpu --extra tab
uv run --no-sync python scripts/transcribe_tab.py      # 本ディレクトリを再生成（CPU で約 3 分）
uv run --no-sync python scripts/verify_tab.py          # 検証（Basic Pitch / mir_eval があれば一致率も計算）
```
